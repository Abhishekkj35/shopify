# Wardrobe – E-Commerce Platform

Wardrobe is a full-stack MERN e-commerce web application that enables users to browse products, add items to cart, and securely complete purchases. The platform supports user authentication, product management, and payment processing while providing a responsive and modern shopping experience.

# Features

Product Catalog Browsing

User Authentication System

Shopping Cart Management

Secure Checkout and Payment Integration

Order Processing System

Role-Based Access Control

Responsive UI Design

# Tech Stack
Frontend: React.js, Tailwind CSS, JavaScript

Backend: Node.js, Express.js, REST APIs

Database: MongoDB, Mongoose

Payment Integration: Stripe

Other Tools: Git, GitHub

# Application Workflow
User visits the homepage.

User browses products available in the store.

User registers or logs into their account.

User adds selected products to the shopping cart.

User proceeds to checkout and completes payment.

Order is processed and confirmation is generated.
